# 종료할 때 방문 기록 삭제

Chrome의 마지막 창을 닫을 때 방문 기록, 주소창 검색 기록과 웹사이트 검색창의 입력 기록을 삭제하는 Manifest V3 확장 프로그램입니다. 종료 과정에서 삭제가 중단될 가능성에 대비해 다음 Chrome 시작 시 한 번 더 정리합니다.

쿠키, 로그인 정보, 비밀번호, 다운로드 파일 및 다운로드 목록은 삭제하지 않습니다.

## 설치 방법

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `chrome-history-cleaner` 폴더를 선택합니다.

설치 후 확장 프로그램 아이콘을 누르면 자동 삭제 옵션을 변경하거나 즉시 삭제할 수 있습니다.

확장 프로그램 아이콘을 누르면 팝업이 열리면서 전체 기간의 방문·검색·양식 기록, 캐시와 다운로드 목록을 즉시 삭제합니다. 로그인 상태를 보존하기 위해 쿠키, 비밀번호와 사이트 저장공간은 삭제하지 않으며, 다운로드한 실제 파일도 유지합니다.

파란 방패와 시계 모양의 전용 아이콘은 이 확장 프로그램을 위해 새로 생성한 이미지이며, 외부 아이콘의 저작권이나 라이선스에 의존하지 않습니다.

## 삭제 범위

- 아이콘 클릭 시 삭제: Chrome 로컬 방문 기록, 주소창 검색 항목, 양식 입력 기록, 캐시, 다운로드 목록
- 자동 종료/시작 시 삭제: 방문 기록, 주소창 검색 항목, 양식 입력 기록
- 유지: 쿠키, 로그인 상태, 저장된 비밀번호, 사이트 저장공간, 다운로드한 실제 파일
- 제외: 북마크, 검색엔진이 실시간으로 제공하는 추천어, Google 계정의 별도 활동 데이터

## 동작상 제한

Chrome은 종료 직전 확장 프로그램의 비동기 작업 완료를 보장하지 않습니다. 그래서 마지막 창을 닫을 때 삭제를 시도하고, 다음 시작 시 다시 삭제하는 방식으로 누락을 보완합니다.
